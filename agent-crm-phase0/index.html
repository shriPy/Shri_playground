Processing Partial Refunds for Merchant Returns
Payments · Updated Aug 2026 · 94% helpful
▼

When a customer returns part of an order financed through Affirm, the merchant processes the return and notifies Affirm of the credit amount. This guide covers how to verify and apply partial refunds to the customer's loan.

Verification Steps

  • Confirm the merchant return in the loan servicing system using the order ID and RMA number
  • Verify the return amount matches the merchant credit notification
  • Check that the return was processed within the eligible return window (typically 30 days)
  • Ensure the customer's identity is verified before applying credits

Applying the Refund

  • Navigate to the loan detail page and select "Apply Merchant Credit"
  • Enter the credit amount and link to the merchant return confirmation
  • The system will recalculate remaining payments proportionally
  • Send confirmation to the customer via email or secure message

Timeline Expectations

Merchant returns typically take 5–10 business days from return confirmation to credit posting. If the return was confirmed more than 10 business days ago and no credit is visible, escalate to Loan Servicing.

Wayfair Merchant Return Policy & Affirm Integration
Merchants · Updated Jul 2026 · 88% helpful
▼

Wayfair processes returns through their standard RMA workflow. Affirm receives automated credit notifications via the MuleSoft integration, typically within 3–5 business days of the merchant processing the return.

Common Issues

  • Delayed merchant notification — check MuleSoft logs for pending credits
  • Partial vs. full return mismatch — verify item-level return details
  • Customer returned items to wrong address — requires merchant confirmation
Loan Balance Adjustments After Refund
Payments · Updated Sep 2026 · 91% helpful
▼

After a merchant credit is applied, the loan servicing system automatically recalculates the payment schedule. The customer will see updated remaining payments in their Affirm app within 24 hours.

Escalation: Refund Not Received After 10 Business Days
Escalations · Updated Jun 2026 · 82% helpful
▼

If a merchant return was confirmed more than 10 business days ago and no credit has posted, create an escalation ticket to Loan Servicing with the order ID, RMA number, and merchant return confirmation screenshot.

Experience Brief

Voicecall Agent Experience

Updating the current voice call screen for Agents

Problem Statement

  • 1 Auth Status banner is easy to miss. It sits above the agent's primary work area. On transferred calls, where re-confirming identity is safety-critical, agents may overlook it entirely.
  • 2 Call summary is isolated. Decagon's AI summary is surfaced in a separate panel with no connection to auth status or transfer context.
  • 3 Transfer context disappears. Transfer reason, verification status, and transfer summary only appear inside a specific flow screen. Navigate away or land on a different flow path — the context is lost.
"An agent answering a transferred call has to open a flow step, check the top banner, and scan a separate summary panel to piece together: who this customer is, whether they're verified, and what they were transferred for. This is disjointed and slow — especially at the start of a call."

Proposed — Unified Voice Call Context Panel

A
Authentication Status All call types · VoiceCall.Auth_Status__c · Prominent badge, always visible at top
B
AI Call Summary Inbound / AI-assisted · VoiceCall.Decagon_Summary__c · Renders only when non-blank
C
Incoming Transfer Context Transferred calls only · Voice_Call_Extension__c on PreviousCallId
